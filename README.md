# Zohaib Munir — Graphic Design Portfolio

This is Zohaib Munir's personally owned public portfolio website.

## Public website

After GitHub Pages finishes its first deployment:

https://zohaibmunnir.github.io/zohaib-munir-portfolio/

## Visual editing dashboard

1. Open https://app.pagescms.org
2. Sign in with the GitHub account `zohaibmunnir`.
3. Install or authorize Pages CMS for this repository when prompted.
4. Open `zohaib-munir-portfolio`.
5. Select **Portfolio Website Editor**.
6. Edit text, services, projects, images, contact details, or main colors and save.

Every saved edit is stored in this GitHub repository and automatically republishes the public website.

## Ownership

The repository and website are controlled by the GitHub account that owns this repository. They do not depend on a ChatGPT subscription.
